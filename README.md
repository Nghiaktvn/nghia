# WinForms Student App

A small Windows Forms application for Software Engineering Lab 5. It accepts a student name and a course name, then displays the entered details.

## Requirements

- Windows
- .NET Framework 4.8
- Visual Studio with .NET desktop development, or the .NET SDK with framework reference assemblies

## Build

Open `WinFormsStudentApp.csproj` in Visual Studio and build the project. Run the application, enter both fields, and select **Show Details**.

## Source code management

This repository records the initial project in GitHub. Collaboration steps require a second student to join the repository and make their own commits.
